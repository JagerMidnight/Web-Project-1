Central Processing Unit

The CPU is the brain of the computer, it processes instructions and performs calculations. It is responsible for executing the instructions provided by software. It uses binary to perform actions and calculations.

Graphic Processing Unit

The GPU is responsible for rendering images, videos, and animations. It is designed to handle multiple tasks simultaneously, making it ideal for gaming and graphic design.

Memory Modules

The RAM holds onto data temporaily while the computer is running. It is volatile memory, meaning it loses its contents when the power is turned off. RAM is used to store data that the CPU needs to access quickly.

Solid State Drives

The SSD is a non-volatile storage device that uses NAND chip-based flash memory to store data. It has no moving parts, making it faster and more reliable. It also has lower power consumption and generates less heat compared to hard drives. They are sometimes more expensive than hard drives, but most of the time they are about the same price. Unlike hard drives, SSDs allow for stupidly working mounting options, such as duct taping it to the case, purely because it has no moving parts. This is not recommended, but it is possible. They come in sizes of 3.5".

Hard Disk Drives

The hard disk drive (HDD) is a non-volatile storage device that uses magnetic storage to store and retrieve digital data. It has moving parts and you cannot have magents near it. They come in sizes of 3.5" and 2.5", most commonly 3.5"

Solid State Hybrid Drive

The solid state hybrid drive works by combining the cheap availablity of a solid state drive, with the cheap bulk storage of a hard drive.
