Operating Systems

This is a simple page about explaining what operating systems are, why they are important, etc.

  • Windows
  • iOS
  • MacOS
  • Linux Kernel

Windows

Windows is currently the most commonly used operating system by far. (about 76% of the desktop market or 1 billion users) Recently however, Microsoft (the company behind windows) has posted numerous bad updates, most of them causing issues such as your audio not working, and have been doing this for the past while. Multiple people are thinking about swapping Windows over to a different operating system, such as linux.

iOS

iOS covers a high percentage of users (1-1.5 billion users, about 31% of the mobile market) And is the operating system used by apple for their iPhones and iPads. This Operating system powered all mobile and non-desktop devices in the apple ecosystem until 2019, when apple changed the naming of the operating systems away from iOS into tvOS, iPadOS, watchOS, and audioOS. iOS is still used today, powering iPhones and was the basic operating system used on all of apple's hardware until present. iOS was based on MacOS.

MacOS (X)

MacOS has a fair number of users, but it is very few in comparision to windows. It has aobut 100-500 million users, or about 17% of the desktop market. It is a desktop operating system used for all of apple's desktop and laptop systems.

Linux Kernel

The Linux Kernel is not a OS, but a open-source kernel. Many different operating systems all use the linux kernel. And are primarily found in cloud enviroments, servers, or power users who use linux as a desktop. Most linux "operating systems" are based on different operating systems (distros), for example, the most common one is Debian-based or "deb-based" distros, one example that is quite popular and common is Ubuntu, which is Deb-Based. Because of the huge list of distributions. I cannot cover all of the operating systems in the linux ecosystem. Instead, I will go over the Kernel, most commonly known information, and the most commonly known base operating systems.

Package Manager
There is a good chance you will discover and hear the term package manager when using linux. It refers to the software developed by someone that allows you to easily install software, manage permissions at times, and update your system. You will most commonly see the Advanced Package Tool (APT)
Bourne-Again SHell (BASH)
Bash is a shell, most commonly found in Ubuntu. It is a popular terminal enviroment that can be easily understood even to beginners.
Deb-Based
Deb-based refers to different linux distributions/operating systems that are based on debian. They are the most common distributions for beginners to use. An few examples of deb-based distros include Ubuntu, Linux Mint, and Proxmox VE.
RPM / Red Hat-Based
These are operating systems/distributions that are based on the red hat / fedora operating systems
Gentoo-Based
These are distros that are based on the gentoo operating system. Gentoo is not designed ideally to be used by beginners. It requires you to compile your own software from the source code locally using Gentoo's package manager, Portage.
Independant / Not based on any distro
These are distributions that are not based on any other operating system. They use their own package manager, such as Nix Package Manager (NixOS), eopkg (Solus), or runit instead of systemd and xbps as its package manager (Void Linux)
